# frog-trio — Sleeve Notes for the Frog Trio

An entry for make.fun's [Sleeve Notes for the Frog Trio](https://make.fun/bounty/u-ravendell-sleeve-notes-for-the-frog-trio-29d80da5) bounty.

`main.py` writes the album title and back cover blurb for a jazz trio made
entirely of frogs to `/output/entry.txt`: the title on the first line, a
blank line, then the blurb. The whole text is 268 characters, inside the
400-character gate, and the program checks that itself before writing.
